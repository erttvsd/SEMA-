# نظام إدارة علامة «سِيمَا الخَيْر»

> **تَعْرِفُهُم بِسِيمَاهُم**
> العلامة الوطنية الليبية للمساهمة في الأعمال الخيرية والإنسانية والتنموية

نظام إداري متكامل وموقع واجهة عربي (RTL) لتشغيل العلامة: السجل العام والتحقق الرقمي، وبوابة
الشركاء وبوابة الجمعيات، ومسار الترخيص والاعتماد بمراحله التسع، والتقييم والتدقيق والزيارات غير
المعلنة، والالتزام السنوي والمساهمات وإثباتاتها، والجزاءات والتظلمات، وحماية النزاهة والمراقبين،
والتقارير والمؤشرات والمالية.

القواعد ليست نصوصاً معروضة في الواجهة: **الخادم يُنفِّذها**. الفصل الوظيفي بين وضع المعيار
والتقييم وقرار الترخيص والتظلم مفروض على مستوى الـ API، وتقرير التقييم يُرفض إن حمل توصية،
وقرار الترخيص يُرفض قبل ورود تقرير الوقائع، والمساهمة لا تُحتسب قبل إقرار الاستلام من المنظمة
المتلقية، والنشر العلني لملاحظات لجنة النزاهة لا يملكه المدير التنفيذي.

## التشغيل

```bash
npm install          # سبع حزم: express · better-sqlite3 · bcryptjs · jsonwebtoken · multer · qrcode · nodemailer
npm run seed         # بناء قاعدة البيانات وتوليد البيانات التصويرية وملفات الإثباتات
npm start            # http://localhost:3000
```

لا أدوات بناء ولا خطوة ترجمة للواجهة. المتطلب الوحيد Node.js 20 أو أحدث.

| أمر | ما يفعله |
|---|---|
| `npm start` | تشغيل الخادم على المنفذ 3000 (أو `PORT`) |
| `npm run seed` | تصفير قاعدة البيانات وإعادة بناء البيانات التصويرية كاملةً |
| `npm run reset` | حذف `storage/` بكامله ثم إعادة البناء |
| `npm test` | الاختبارات كلها — يُشغّل خادماً خاصاً على قاعدة مؤقتة، ويبنيها، ويختبر: الوحدات (116) · مسارات المستخدم (20) · قواعد اللائحة (63) · الوحدات المضافة (220) · الانحدار الأمني (70) · الواجهة في متصفح حقيقي (258) — 747 فحصاً |
| `npm run docs` | إعادة توليد `docs/02-مصفوفة-الصلاحيات.md` من `server/rbac.js` |
| `npm run init -- --email … --name "…"` | **قاعدة إنتاج نظيفة**: المراجع النظامية وحساب المدير التنفيذي الأول — بلا بيانات تصويرية |
| `npm run backup` | نسخة احتياطية متّسقة مع فحص سلامتها وبصمتها |
| `npm run restore -- <ملف>` | استعادة نسخة والخادم متوقف، بعد التحقق منها وحفظ القاعدة الحالية جانباً |

متغيرات البيئة: `PORT` · `SEMA_JWT_SECRET` (إلزامي إذا `NODE_ENV=production`) · `SEMA_DATA_DIR` ·
`SEMA_PUBLIC_URL` (أساس روابط رموز QR والبريد) · `SEMA_SMTP_URL` (الخادم البريدي) · `SEMA_TRUST_PROXY` (خلف وكيل عكسي) ·
`SEMA_BACKUP_DIR` · `SEMA_JOBS=0` (تعطيل المهام الآلية) · `SEMA_JOBS_HOURS` (دوريتها، الافتراضي 6) ·
`SEMA_DEMO=0` (إخفاء حسابات العرض من صفحة الدخول). النموذج الكامل في [`.env.example`](.env.example)،
ودليل الإنتاج كاملاً — Docker والوكيل العكسي والبريد والنسخ والاستعادة — في [الوثيقة 05](docs/05-التشغيل-والنشر.md).

## ما ينفّذه النظام

### الحوكمة والفصل الوظيفي
19 دوراً و75 صلاحية، والأدوار الأربعة المحجوزة (وضع المعيار · التقييم والتدقيق · قرار الترخيص ·
التظلم وحماية النزاهة) لا يجوز الجمع بين اثنتين منها — والنظام يرفض التعيين المخالف بـ`422`
عند إنشاء المستخدم وعند تعديل أدواره. المرجع: [مصفوفة الصلاحيات](docs/02-مصفوفة-الصلاحيات.md).

### مسار الترخيص والاعتماد
تسع مراحل بمددها القصوى محسوبةً **بأيام العمل**، مع رصد تجاوز المدة لكل مرحلة، وتقرير وقائع
بلا توصية، وقرار مسبَّب كتابي. وعند المنح يُنشئ النظام في معاملة واحدة رقم الترخيص ورمز التحقق
وملف الالتزام والفاتورة بالتناسب وإقرار الامتثال المستقبلي.

### الالتزام والمساهمات
الالتزام = الأعلى من النسبة أو الأرضية (مُختبَر مقابل أمثلة ملحق 1 الستة كلها)، مع سقوف المسارات
وقاعدة النصف النقدي وسقف التركّز 60% وسقف الاستيعاب 200%، ورفض المسارات غير المحتسبة بسبب
مسبَّب، وتكييف العجز آلياً إلى إمهال أو تعليق.

### الإثباتات
41 نوع إثبات، وكل ملف ببصمة SHA-256 تكشف التكرار، وحالة تحقق بمن تحقّق ومتى وبملاحظته، وتواريخ
صلاحية بتنبيه ما يقارب الانتهاء، وعلامتَي **سرّي** و**منشور**، وتقييد كل تنزيل في سجل التتبع.
والبيانات التصويرية تحمل 1,054 مستنداً **معروضاً فعلاً** بترويسة العلامة.

### التدقيق
خطة عيّنة عشوائية ببصمة موثّقة **قابلة لإعادة التحقق**، تحترم نسب المادة (25) وتضمن ألا تقل
الزيارات غير المعلنة عن 10% — ولا يرى المرخَّص له الزيارة غير المعلنة قبل تنفيذها.

### المسار الكامل من التسجيل إلى التجديد
تسجيل ذاتي يوقّع إقرارات الدخول إلكترونياً ويحفظها مستندات · فحص الاستيفاء والإخطار بالنواقص ·
**استكمال النواقص** من الطالب خلال 20 يوم عمل · التقييم وتقرير الوقائع · القرار المسبَّب · الشهادة ورمز QR ·
إقرار الامتثال السنوي ثم **وقائع الوحدة ثم قرار اللجنة** (تجديد · خفض · تعليق · سحب) · **التجديد** و**رفع المستوى**
بفرق الرسم · إقرار الاستلام وتقرير الأثر بملفاتهما · **الموافقة المسبقة على البرامج الذاتية**.

### المشاورة العامة على المعايير
مقترح ← مشاورة لا تقل عن 30 يوماً للتعديل الجوهري ← مداخلات عامة بلا حساب ← رد اللجنة على كل مداخلة ←
إغلاق ونشر الملخص ← قرار المجلس (أو الجمعية العمومية لتعديل النظام الداخلي) — مع اشتراط ستين يوماً قبل نفاذ
تعديل الرسوم والأرضيات.

### المراسلات مع الأمانة
بديل مكتوب للبريد والهاتف: الشريك والمنظمة والمراقب يراسلون الأمانة بشأن ملفهم — أو بشأن طلب أو فاتورة أو
إقرار أو مساهمة أو تصميم أو جزاء بعينه — بمرفقات، وتُوجَّه المراسلة آلياً إلى الوحدة المختصة (المالية، التقييم،
العلاقة بالمنظمات، السجل)، وتُسند إلى موظف، وللأمانة **ملاحظات داخلية ومرفقات سرّية لا تراها الجهة**، والجهة
ترى «الأمانة التنفيذية» لا اسم الموظف. ولجنة منح الترخيص خارج المراسلات لأنه يُحظر عليها التفاوض مع الطالب.

### تقويم المواعيد والبحث الشامل
تقويم شهري لكل موعد يخص المستخدم بحسب صلاحياته ونطاق ملفه — مواعيد مراحل الطلبات، وانتهاء التراخيص
والاعتمادات، والإقرارات، واستحقاق الفواتير، والموافقات الضمنية، والبتّ في التظلمات، وتحوّل التعليق إلى سحب،
ومهل النزاهة، والتدقيق المجدول (دون الزيارات غير المعلنة لصاحب الملف)، والاجتماعات، والمشاورات — مع المتجاوز
منها. وبحث شامل من الشريط العلوي في كل ما يملك المستخدم الاطلاع عليه، مجمَّعاً بحسب النوع.

### المهام الآلية
اثنتا عشرة مهمة تُنفّذ المواعيد النظامية بنفسها عند الإقلاع وكل ست ساعات ويدوياً: تحويل التعليق إلى سحب بعد ستة
أشهر، انتهاء التراخيص والاعتمادات، انقضاء حق الاستعمال لعدم تقديم الإقرار، الموافقة الضمنية على التصاميم،
حفظ الطلبات، الرسوم المتأخرة، انقضاء النشر، تصعيد ملاحظات النزاهة، والتذكير بالمواعيد القريبة — ومعها
إعادة إرسال البريد المتعثر والنسخ الاحتياطي اليومي.

### الحساب والأمان
سياسة كلمات مرور، وحدّ لمحاولات الدخول، و**استعادة كلمة المرور** برابط لمرة واحدة، و**كلمة مرور مؤقتة** يلزم
تغييرها لكل حساب تُنشئه الإدارة، و**التحقق بخطوتين** (TOTP بأي تطبيق مصادقة، مع رموز استرداد) قابلاً للإلزام على
حسابات الحوكمة والأمانة، وإسقاط الجلسات عند تغيير كلمة المرور أو الأدوار أو إيقاف الحساب، وبريد صادر مقيَّد
برسائل أمان لا تُوقَف، وقائمة أنواع ملفات مسموحة، وعرض كل مستند معزولاً (`CSP: sandbox`)، وترويسات أمان
عامة، ومنع الإقلاع بسرّ افتراضي في الإنتاج. التفاصيل في الوثيقتين 04 و05.

### النسخ الاحتياطي
نسخة يومية تلقائية بلقطة متّسقة والخادم يعمل، مع فحص سلامتها وبصمتها والاحتفاظ بآخر 14 نسخة، ونسخ وتنزيل
يدويان مقيَّدان بالصلاحية وبسجل التتبع، واستعادة من سطر الأوامر تتحقق من النسخة قبل أي تغيير.

### الفلترة والتقارير
فلترة مركَّبة على كل جدول (قوائم، حدود دنيا وعليا، مدد، بحث حر، ترتيب، ترقيم) محفوظة في عنوان
الصفحة فيصلح مشاركة الرابط. وعشرة تقارير جاهزة بتصدير CSV يفتح في Excel العربي مباشرةً،
مع المؤشرات الستة عشر ومستهدفاتها الخمسية وسجل المخاطر.

## ملاحظات نشر

- الدليل الكامل في [الوثيقة 05](docs/05-التشغيل-والنشر.md): `npm run init` لقاعدة نظيفة، و`docker compose up -d`،
  وإعداد nginx، والبريد، والتحقق بخطوتين، والنسخ والاستعادة، وقائمة التحقق قبل الإطلاق.
- `SEMA_JWT_SECRET` **يجب** تعيينه في الإنتاج — والخادم يرفض الإقلاع بالقيمة الافتراضية.
- المستندات تُخزَّن في `<DATA_DIR>/uploads/` وتُقدَّم عبر مسار محمي بفحص الصلاحية والنطاق والسرّية،
  لا عبر مجلد ثابت مفتوح.
- خلف وكيل عكسي: `SEMA_TRUST_PROXY=1` — ولا يُوثَق بترويسة `X-Forwarded-For` بدونه، فلا يتجاوز العميل
  حدود المحاولات بتزويرها.
- الانتقال إلى PostgreSQL يقتصر على `server/db.js` لأن الاستعلامات مكتوبة SQL قياسياً.

## تنويه
