# البيانات التصويرية

بيانات افتراضية بالكامل لأغراض العرض. المعايير والنسب والأرضيات والرسوم والمدد **مطابقة**
لما في لائحة الاعتماد والترخيص والرقابة والنظام الداخلي؛ أما أسماء المنشآت والمنظمات والأشخاص
والأرقام المالية فمُولَّدة.

المولِّد **حتمي**: بصمة ثابتة (`rngState = 20260815`) فتتكرر النتيجة نفسها عند كل إعادة بناء،
وهو ما يجعل لقطات الشاشة والاختبارات مستقرة.

```bash
npm run seed     # تصفير وإعادة البناء الكامل — يمحو قاعدة البيانات والملفات المحمَّلة
```

## حالات مقصودة للعرض

بُنيت هذه الحالات تحديداً لتُظهر إنفاذ مواد بعينها:

| الحالة | ما تُظهره |
|---|---|
| **شركة ليبيانا للاتصالات** — إيراد 221 مليوناً، المستوى الأول | الشريحة (و) بأرضية نسبية 0.10% من الإيراد؛ والالتزام 300,000 د.ل بالنسبة لا بالأرضية؛ والرسم السنوي مطبَّق عليه **السقف المطلق 30,000** (المادة 34/5) |
| **شركة الساحل للمياه** — المستوى الخامس | نطاق الترخيص خط إنتاج «قارورة الخير» بمركز تكلفة مستقل، وتدقيق سنوي إلزامي بلا عيّنة (المادة 7) |
| **شركة الشمس للتبغ** | مرفوضة لقائمة الاستبعاد (المادة 10/1)، ومع ذلك **رسم الطلب غير مستردّ** (المادة 34/1)، وتظلمها أُيِّد فيه قرار الرفض |
| **جمعية العطاء للتكافل** — نسبة إدارية 28.9% | تجاوز سقف 25% فمعلَّقة صفة اعتمادها (المادة 15 و32) |
| **جمعية النخبة للأعمال الخيرية** — 36.3% وكلفة جمع 41% | سحب الاعتماد لتجاوز السقفين (المادة 32) |
| **مؤسسة الإحسان للتنمية** — نسبة إدارية 4% | تنبيه «ما دون 5% يستوجب فحصاً إضافياً» (المادة 15) |
| **حرفيون وفنانون ومبدعون** (6 ملفات) | الشريحة (أ) وأرضياتها الصغيرة، وإمكان الإعفاء من رسم الطلب في السنوات الثلاث الأولى |
| **الشركاء المؤسسون** (12 منشأة + 12 منظمة) | صفة دائمة في السجل وأولوية في المعالجة **دون أي تخفيف في المعايير أو التدقيق** (المادة 39) |
| **مراقبان مرفوضان** | بلوغ القطاع سقف المراقبَين (المادة 34/3) |
| **مراقب أُنهيت صفته** | قرار مسبَّب عند الإخلال بالسرّية (المادة 34/6) |
| **مقيّم أعلن تعارض مصالح** | إقرار مصالح سنوي يمنعه من تقييم جهة قدّم لها خدمة (المادة 20/4) — والنظام يرفض تكليفه |
| **ملاحظة نزاهة منشورة** | انقضاء التسعين يوماً دون استجابة المجلس، فمارست اللجنة صلاحية النشر العلني (المادة 23/3) |
| **طلب متأخر واحد** من أصل 9 مفتوحة | رصد تجاوز المدة المعيارية دون إغراق اللوحة بتنبيهات غير واقعية |

## الحسابات التصويرية

كلمة المرور لكل الحسابات: **`Sema@2026`**
والقائمة الكاملة معروضة في صفحة الدخول، ويكفي الضغط على الحساب لتعبئة بياناته.

| الدور | البريد |
|---|---|
| رئيس مجلس الأمناء | `chair@sema.ly` |
| عضو مجلس الأمناء | `board1@sema.ly` … `board7@sema.ly` |
| عضو الجمعية العمومية | `ga1@sema.ly` |
| لجنة المعايير | `standards1@sema.ly` … `standards3@sema.ly` |
| مدير وحدة التقييم والتحقق | `evaldir@sema.ly` |
| مقيّم | `assessor1@sema.ly` … `assessor3@sema.ly` |
| مدقق ميداني | `auditor1@sema.ly` · `auditor2@sema.ly` |
| لجنة منح الترخيص | `licensing1@sema.ly` … `licensing3@sema.ly` |
| لجنة التظلمات | `appeals1@sema.ly` … `appeals3@sema.ly` |
| لجنة حماية النزاهة | `integrity1@sema.ly` … `integrity4@sema.ly` |

### مسارات مقترحة للتجربة

1. **من الطلب إلى الترخيص**: ادخل بـ`assessor1` وافتح طلباً مقدَّماً وافحص استيفاءه، ثم ارفع
   تقرير الوقائع — وحاول إضافة توصية ليرفضها النظام. ثم ادخل بـ`licensing1` وأصدر القرار
   المسبَّب، ثم افتح صفحة التحقق العامة برقم الترخيص الجديد.
2. **الفصل الوظيفي**: ادخل بـ`director` ← `#/rbac` ← تبويب «فحص تعيين»، واختر «مقيّم» مع
   «عضو لجنة منح الترخيص».
3. **حدود المدير التنفيذي**: بحساب `director` جرّب إصدار جزاء — الصلاحية غير ممنوحة أصلاً،
   وواجهة الجزاءات لا تعرض له زرّ الإصدار.
4. **نطاق المراقب**: ادخل بـ`observer1` وحاول فتح `#/licensees/1` مباشرةً.
5. **سقف الاستيعاب**: بحساب `partner1` سجّل مساهمة تتجاوز سقف منظمة، ولاحظ الرفض المسبَّب.
6. **العيّنة العشوائية**: بحساب `evaldir` افتح `#/audit-plan` وأعد التوليد ببصمة جديدة ثم
   بالبصمة نفسها للتحقق من قابلية إعادة الإنتاج.
